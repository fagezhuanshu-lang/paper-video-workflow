# 支持范围与验收边界

本项目是MIT许可的原创流程和渲染脚本。图片字体、依赖与素材各自遵守其许可证；随包字体应使用仓库声明的开放许可字体。用户原片、人物照片、文案、歌曲及个人授权文件不进入公开仓库。

## 当前目标

- 读取本地视频的一个连续区间，以及用户提供或实际复核的字幕/计划。
- 用公开组件表达标题、步骤、对比和观点，按合同输出视频、配乐混音及主题封面。
- 用真实原片帧制作照片封面，或不带照片制作纯图文封面。
- 在生成后检查媒体规格、帧数、音轨和封面输出，并保留可复核记录。

## v2.1 的人物运动修复

v2.0 的公开渲染器把人物画在固定矩形中，文字变化没有带动人物窗；只检查编码、时长和封面无法发现这个缺陷。v2.1 根据场景生成位置和尺寸关键帧，并在切换期间逐帧插值：标题/引用使用大窗，步骤/对比缩小下移，再回到大窗。相同景别连续出现时保持稳定，不强制所有镜头持续晃动。

可用场景的 `presenter` 字段覆盖默认景别，并用项目级 `presenter.fit` / `anchorY` 调整取景；详见[项目格式](project-format.md)。输出的 `presenter-motion.json` 说明本次运动轨迹。除轨迹计算测试外，合成示例采用静止测试图，并从编码后的 MP4 测量标记位置与宽度，避免把人物原片自身的动作误认为模板运动。

这项修复处理公开版缺少人物缩放与移动的问题。它没有把原创公开引擎变成 MotionGit，不能据此承诺原生文字、材质、音效或缓动完全一致。

实际支持的分辨率、帧率、主题和场景以当前合同与验证器为准。封面固定输出9:16和3:4，这些是本流程设计规格，不是所有平台唯一标准。当前封面抽帧只接收SDR；HDR需要明确色彩转换流程。

## 不包含

- 预装的语音识别模型（可选转写会另行下载或读取自己的模型）、自动去口误、任意多剪口拼接和逐词强制对齐。
- MotionGit个人 `.motion` 包、登录凭据、受保护核心或未经许可的科技控制台代码/资产。
- MotionGit官方动画、关键帧、配套音效的逐项复刻；这里的公开动画与程序音效是本项目自己的实现。
- 用户曲库、用户照片、付费图像生成、自动发布与代用户发送内容。
- 对任何模型、机器、素材或桌面代理的“完全自动、完美、逐帧相同”保证。

想使用 MotionGit 完整版，应由使用者自行取得许可，并按[原生制作说明](motiongit-native.md)调用官方入口。缺少所需模板、依赖或权限时说明实际缺口，不静默改用公开引擎；只有用户明确接受公开风格后才改走 `build`。下载本仓库不会自动获得第三方授权。

## 何时可以说完成

机器检查通过后，还应看编码后开头/切换/最长字幕/结尾，试听首句/中段/末句，核对主体裁切与声音可懂度；两种封面均需查看全尺寸与缩略图。标题应由实际原话支持，字幕需保留否定与范围，音效不应制造原话没有的“已经完成”含义。

分别记录：已渲染、机器检查、实际视觉检查、实际试听、用户审美评价。合成测试没有真人和口播时，不记真人口播验收通过；用户没有评价时，不写用户已批准。测试矩阵以 [validation.json](validation.json) 和对应提交的 GitHub Actions 结果为准。v2.0 曾完成托管 Windows 环境测试，这不代表后续修改已经验证；v2.1 应查看其自身提交的检查结果。WorkBuddy 端到端实测、官方阶段封装全流程与新模板版本分别记录，不借用公开引擎 CI 的通过结果。

发现问题时先修复具体计划、字幕、音量或布局，再用新输出目录重建。不得以裁掉原话、隐藏音轨或跳过检查来制造“通过”。
